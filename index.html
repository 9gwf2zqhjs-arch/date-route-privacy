데이트 루트 개인정보처리방침

시행일: 2026년 10월 21일

데이트 루트(이하 "서비스")는 사용자가 인스타그램 다이렉트 메시지(DM)로 보낸 게시물·릴스 공유를 받아, 장소·행사 정보를 정리하고 지도와 데이트 루트로 보여 주는 개인 프로젝트입니다.

1. 수집하는 정보

  • 사용자가 서비스 계정에 DM으로 보낸 메시지 내용 (공유된 게시물·릴스의 링크와 미디어 주소, 텍스트)
  • 메시지를 보낸 인스타그램 계정의 고유 ID

그 밖의 개인정보(이름, 연락처, 위치, 결제 정보 등)는 수집하지 않습니다.

2. 이용 목적

공유된 장소·행사 정보를 추출해 사용자 본인의 지도와 데이트 루트를 만드는 데에만 씁니다. 광고, 판매, 제3자 제공에 쓰지 않습니다.

3. 보관과 삭제

정보는 서비스 운영자의 기기에만 저장되며, 사용자가 요청하면 지체 없이 삭제합니다. 서비스를 종료하면 모든 정보를 삭제합니다.

4. 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 메시지 수신은 Meta Platforms의 Instagram API를 통해 이루어집니다.

5. 데이터 삭제 요청

아래 이메일로 인스타그램 계정명과 함께 삭제를 요청하면 관련 정보를 모두 삭제하고 회신합니다.
